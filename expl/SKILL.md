# 코드 설명 강의 스크립트 작성

강사가 붙여넣은 코드에 대해 (1) 수강생에게 읽어 줄 강의 스크립트와 (2) VS Code에서 따라 칠 수 있는 변형 코드 및 변형 의도를 작성한다.

## 출력 구성

### 1. 원본 코드 설명

- 붙여넣은 코드를 그대로 코드 블록으로 다시 보여 준다.
- **강의 스크립트**: 코드를 위에서부터 한 줄씩 설명한다. 각 문법 요소의 역할, 실행 결과, 실행 흐름을 설명한다.
- VS Code에서 마우스를 올려 타입 추론 결과를 확인하는 등, 화면에서 직접 보여 줄 수 있는 포인트를 포함한다.
- **원본 코드의 실제 동작을 반드시 검증한다.** strict 모드 TypeScript에서 원본 코드에 오류가 표시되는지 확인한다. 예를 들어 `const day = 2;` 후 `switch (day) { case 1: ... }`는 리터럴 타입 때문에 `Type '1' is not comparable to type '2'` 오류가 발생한다. 이런 경우 "주의" 항목으로 원인과 해결 방법(예: `const day: number = 2;`)을 설명하고, 이후 변형에서 해결된 코드를 사용한다.

### 2. 변형 코드

- 변형 개수: 사용자가 지정하면 그 개수를 따른다. 지정하지 않으면 5~6개로 한다.
- 각 변형은 다음 세 부분으로 구성한다.
  1. 변형 코드 (코드 블록, 수강생이 그대로 입력할 수 있는 완전한 코드)
  2. **변형 의도**: 무엇을 설명하려고 코드를 어떻게 바꿨는지 1~3문장
  3. **강의 스크립트**: 강사가 읽을 설명
- 오류를 보여 주는 줄에는 `// 오류` 주석을 붙이고, 스크립트에서 실제 오류 메시지의 내용을 설명한다. 확인 후 해당 줄을 삭제하거나 주석 처리하도록 안내한다.

### 3. 진행 순서 요약

마지막에 표로 정리한다: `| 순서 | 변형 | 설명 포인트 |`

## 변형 설계 원칙

- 원본에서 한두 군데만 바꾸어 수강생이 차이를 쉽게 알아볼 수 있게 한다.
- 다음 흐름으로 점진적으로 구성한다. 개수가 적으면 가장 교육 효과가 큰 것을 고른다.
  1. 값을 바꿔 다른 실행 경로 확인 (예: true → false, else 도입)
  2. 문법 요소를 빼거나 바꿔 그 역할 확인 (예: break 삭제 → fall-through)
  3. 타입 명시와 타입 추론 비교
  4. 잘못된 타입이나 값으로 TypeScript 오류 확인
  5. JavaScript와 TypeScript의 동작 차이 (예: `"18" >= 18`은 JS에서 자동 형변환, TS에서는 오류)
  6. 실무적 확장 (조건 결합, 삼항 연산자, case 묶기, 유니언 타입 등)
- 앞 변형에서 보여 준 현상을 뒤 변형에서 활용하도록 연결한다 (예: fall-through를 버그로 보여 준 뒤, case 묶기로 의도적 활용).
- 원본 설명에서 다룬 TypeScript 특성(리터럴 타입 등)이 있으면 마지막 변형에서 이를 긍정적으로 활용하는 예를 보여 준다.

## 작성 규칙

- 스크립트는 강사가 그대로 읽을 수 있는 공식적인 존댓말("~합니다", "~보겠습니다")로 쓴다. 구어체 표현은 쓰지 않는다 ("깨지지 않는다" 대신 "정상적으로 동작합니다").
- 제목과 소제목은 단순하고 직설적으로 쓴다 (예: "변형 1: break를 빼면 어떻게 되는가", "변형 2: 타입 명시하기"). 수사적·은유적 표현은 쓰지 않는다.
- 스크립트는 인용 블록(`>`)으로 작성한다.
- 오류 메시지, 추론 타입, 출력 결과는 실제 TypeScript 동작과 일치해야 한다. 확실하지 않은 동작은 단정하지 않는다.
- 결과는 대화 응답으로 바로 제공한다. 별도 파일은 요청이 있을 때만 만든다.

## 예시 (요약)

입력:
```typescript
const age = 18;
const isOldEnough = age >= 18;   // true
if (isOldEnough) { console.log("운전할 수 있습니다"); }
```

변형 구성 예:
1. `age = 16` + else → false일 때의 흐름
2. `: number`, `: boolean` 명시 → 추론과 명시의 차이
3. `const isOldEnough: boolean = "true";` → 문자열과 boolean 구분
4. `const age = "18";` → JS 자동 형변환과 TS의 차단, `Number(age)`로 해결
5. `hasLicense`와 `&&` → 조건 결합
6. 삼항 연산자 → 조건에 따른 값 선택
