# TypeScript 강의 퀴즈

모든 수강생이 **같은 문제, 같은 해설**로 학습하도록 진행하는 퀴즈다.
문제와 해설은 모두 JSON 파일에 정해져 있다. **AI가 문제나 해설을 새로 만들지 않는다.**

## 1. 문제 파일 찾기

- 작업 폴더(워크스페이스 루트)의 `quizzes/` 폴더에서 `section*.json` 파일을 찾는다.
- 사용자가 섹션을 말했으면 해당 파일(예: "섹션 2" → `quizzes/section02.json`)을 연다.
- 섹션을 말하지 않았으면(스킬 이름만 입력한 경우 포함) 파일이 하나뿐이어도 바로 시작하지 않는다. 아래처럼 섹션 목록을 보여 주고 번호를 물은 뒤 답을 기다린다.
  ```
  어느 섹션 퀴즈를 풀까요? 섹션 번호를 입력해 주세요.
  - 2: Section 2. 어휘 구조와 기본 타입 (8문제)
  ```
  목록은 각 파일의 `section`, `title`, 문제 수로 만든다. 목록에 없는 번호를 입력하면 "섹션 N의 문제 파일이 없습니다."라고 알리고 다시 묻는다.
- 파일이 없으면 "quizzes 폴더에 문제 파일이 없습니다."라고 알리고 멈춘다.
- `quizzes/`의 JSON 파일은 **읽기만 하고 절대 수정하지 않는다.** 진행 상황은 아래 스크립트로만 저장한다.

### 이어 풀기 확인

섹션이 정해지면 문제를 내기 전에 저장된 진행 상황을 확인한다.

```
node .claude/skills/quiz/scripts/quiz-progress.mjs show <섹션 번호>
```

- `exists`가 false면 바로 1번 문제부터 시작한다.
- `exists`가 true이고 `stale`이 false면 이렇게 묻고 답을 기다린다.
  ```
  지난번에 문제 {next + 1} / {total}에서 멈췄습니다. (맞음 {correct} / 틀림 {wrong} / 통과 {passed})
  이어서 풀까요, 처음부터 풀까요? (이어서 / 처음부터)
  ```
  - "이어서"(또는 "계속", "응" 같은 긍정): `results`로 점수와 문제별 결과를 되살리고, `next + 1`번 문제부터 낸다. `attempt`가 1이면 그 문제는 이미 한 번 틀린 상태이므로 제목에 "(다시 풀기)"를 붙이고, 이번 답이 두 번째 시도다. 진행 방식 안내는 생략한다.
  - "처음부터": `node .claude/skills/quiz/scripts/quiz-progress.mjs clear <섹션 번호>`를 실행하고 1번 문제부터 시작한다.
  - 그 밖의 입력이면 "이어서 / 처음부터 중 하나로 답해 주세요."라고 다시 묻는다.
- `stale`이 true면 "문제 파일이 바뀌어 처음부터 시작합니다."라고 알리고, clear를 실행한 뒤 1번 문제부터 시작한다.

각 문제의 필드:

| 필드 | 뜻 |
|---|---|
| `id`, `lecture`, `topic` | 문제 번호, 강의 번호, 주제 |
| `question`, `code` | 질문 문장, 코드 블록 |
| `choices` | 보기 `A`, `B`, `C` |
| `answer` | 정답 기호 (사용자에게 미리 보여 주지 않는다) |
| `wrongReasons` | 오답 보기별 "왜 틀렸는지" 설명 (정답은 알려 주지 않는 문장) |
| `explanation` | 정답 해설 |

## 2. 진행 규칙

1. 시작할 때 진행 방식을 한 번만 짧게 안내한다.
   "한 문제씩 3지선다로 냅니다. 틀리면 이유를 듣고 한 번 더 풀 수 있고, 두 번 틀리면 정답을 알려 드리고 다음 문제로 넘어갑니다. 풀기 싫은 문제는 '통과'라고 입력하면 넘어갑니다."
2. `questions` 배열 순서대로 **한 번에 한 문제만** 낸다. 다음 문제를 미리 보여 주지 않는다.
3. 사용자의 답을 기다린다. `A`, `B`, `C`는 대소문자를 구분하지 않는다.
   그 밖의 입력(예: `1`, `2`, 질문, 잡담)은 시도로 세지 않는다. 짧게 답한 뒤 "A, B, C 중 하나로 답해 주세요."라고 다시 묻는다.
4. **정답이면**: "⭕ 정답입니다!"(두 번째 시도면 "(두 번째 시도)"를 붙인다) → `explanation`을 보여 준다 → 맞음 1개를 더한다 → 다음 문제.
5. **첫 번째 오답이면**: "❌ 틀렸어요. (첫 번째 시도)" → 고른 보기의 `wrongReasons`를 보여 준다 → **정답은 알려 주지 않고** 같은 문제를 그대로 다시 낸다.
6. **두 번째 오답이면**: "❌ 또 틀렸어요. 정답은 **X**입니다." → 두 번째로 고른 보기의 `wrongReasons`와 `explanation`을 보여 준다 → 틀림 1개를 더한다 → 다음 문제.
7. **통과**: 사용자가 "통과"(또는 "패스", "pass", "skip")라고 입력하면 확인 없이 바로 넘어간다. 첫 시도든 다시 풀기든 같다. "⏭ 통과했습니다. 정답은 **X**입니다." → `explanation`을 보여 준다 → 통과 1개를 더한다(맞음·틀림에는 넣지 않는다) → 다음 문제.
8. 매 채점(통과 포함) 뒤 `📊 현재 점수: 맞음 N / 틀림 M / 통과 P`를 보여 준다.
9. **진행 상황 저장**: 매 채점(통과 포함) 뒤, 다음 문제를 내기 전에 저장한다. 대화가 갑자기 끊겨도 이어 풀 수 있게 하려는 것이다.
   ```
   node .claude/skills/quiz/scripts/quiz-progress.mjs save <섹션 번호> --next <지금 낼 문제 순번(0부터)> --attempt <그 문제에서 틀린 횟수> --results <지금까지 결과>
   ```
   - `results`는 끝난 문제의 결과를 순서대로 쉼표로 잇는다. `O` = 첫 시도에 정답, `R` = 두 번째 시도에 정답, `X` = 두 번 틀림, `P` = 통과. 예: `O,O,R,X,P`
   - 정답이거나 두 번째 오답이거나 통과면 다음 문제로 넘어가므로 `--next`는 1 늘리고 `--attempt 0`.
   - 첫 번째 오답이면 같은 문제를 다시 내므로 `--next`는 그대로, `--attempt 1`.
   - 마지막 문제를 끝냈으면 save 대신 5장의 clear를 실행한다.
   - 저장 명령이 실패해도 퀴즈는 계속 진행하고, 사용자에게 "진행 상황을 저장하지 못했습니다."라고 한 줄 알린다.
10. **종료**: 사용자가 "종료"라고 입력하면(시도로 세지 않는다) 바로 끝내지 말고 "퀴즈를 종료할까요? (예 / 아니요)"라고 묻는다.
   - "예", "네", "응", "맞아" 같은 긍정 답이면: `## 🛑 퀴즈 종료: 맞음 N / 틀림 M / 통과 P (전체 T문제 중 K문제 진행)`을 보여 준다. 풀던 문제는 점수에 넣지 않고, 정답도 알려 주지 않는다. 푼 문제가 있으면 문제별 결과 표와 📌 복습 포인트(5장과 같은 형식)를 보여 준다. 진행 상황은 지우지 않고, 마지막에 "다음에 `/quiz 섹션 N`을 실행하면 이어서 풀 수 있습니다."라고 알린 뒤 끝낸다.
   - 그 밖의 답이면: "계속 진행합니다."라고 알리고 풀던 문제를 그대로 다시 낸다. 시도 횟수는 그대로 유지한다.

## 3. 해설 규칙

- `wrongReasons`와 `explanation`의 문장을 **그대로** 전달한다. 줄 바꿈이나 강조(굵게, 코드 표기) 정도만 바꿀 수 있다.
- 사용자가 추가 질문을 하면 그 질문에는 자유롭게 답해도 된다. 단, 아직 풀고 있는 문제의 정답을 알려 주지 않는다.
- 문제·보기·정답을 바꾸거나 새 문제를 만들지 않는다. JSON 내용이 틀려 보여도 그대로 진행하고, 끝난 뒤 "문제 파일 확인이 필요해 보입니다."라고 강사에게 알리도록 안내한다.

## 4. 문제 출력 형식

````markdown
### 문제 {번호} / {전체 문제 수} — {topic} ({lecture})

```ts
{code}
```

{question}

- **A.** {choices.A}
- **B.** {choices.B}
- **C.** {choices.C}
````

같은 문제를 다시 낼 때는 제목 끝에 "(다시 풀기)"를 붙인다.

## 5. 마무리

모든 문제를 마치면 `node .claude/skills/quiz/scripts/quiz-progress.mjs clear <섹션 번호>`로 진행 상황을 지우고 아래를 보여 준다.

1. `## 🏁 최종 결과: 맞음 N / 틀림 M / 통과 P`
2. 문제별 결과 표: 번호, 주제, 결과(⭕, ⭕ (재시도), ❌, ⏭ 통과)
3. 📌 복습 포인트: 틀리거나 통과한 문제의 `lecture`와 `explanation`을 한 줄씩 정리한다.
4. "처음부터 다시 풀어 볼까요?"라고 묻는다.
